# mapa-maconaria

Enciclopédia aberta da Maçonaria — ritos, rituais (no nível do que é publicado), graus, princípios, simbolismo, potências, documentos, eventos no Brasil e no mundo e personalidades — com fontes citadas por afirmação e divergências entre potências, ritos, países e épocas registradas lado a lado.

- Regras do projeto: [`CLAUDE.md`](CLAUDE.md)
- Plano: [`docs/PLANO.md`](docs/PLANO.md) · Estado: [`docs/ESTADO.md`](docs/ESTADO.md) · Sessões: [`docs/ORQUESTRACAO.md`](docs/ORQUESTRACAO.md)
- Taxonomia: [`docs/taxonomia.md`](docs/taxonomia.md) · Guia de verbetes: [`docs/verbetes-guia.md`](docs/verbetes-guia.md)
- Catálogo de fontes: [`data/fontes/`](data/fontes/) — validar com `python3 scripts/validar_fontes.py`
